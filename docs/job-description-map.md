# Job Description to Portfolio Project Map

This document tracks how job descriptions are translated into portfolio projects.

## Legal AI / Legal Innovation Role

### Skills Requested

- AI-powered legal technology
- Contract review
- Clause extraction
- Workflow automation
- Predictive analytics
- Document summarization and drafting
- Legal technology evaluation and comparison
- User feedback gathering
- Requirements translation
- Custom AI agents and RAG workflows
- Matter intake
- Knowledge retrieval
- Pilot tracking and ROI metrics
- Testing and validation
- Data privacy and information security awareness
- Training materials and demos

### Portfolio Project

[Legal AI Contract Review Assistant](../projects/legal-ai-contract-review/README.md)

### Why This Project

This is a strong first project because it is specific enough to build, but broad enough to demonstrate many of the skills requested in legal innovation and AI adoption roles. It can start as a free local prototype and later grow into a web app with dashboards, feedback loops, and RAG features.

### First Build Milestone

Load a small public contract sample, extract five important clause types, and produce a structured review report.
