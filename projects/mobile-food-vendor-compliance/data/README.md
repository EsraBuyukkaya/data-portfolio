# Data Notes

Large raw and processed datasets are intentionally not committed to this portfolio repository.

The original project used:

- Suffolk County public restaurant violation records,
- NOAA weather data,
- NY food inspection context data,
- NYC DOH mobile food vendor regulations,
- NY State Sanitary Code references,
- and a curated permit bank.

The source scripts in `src/` show how the pipeline ingests and rebuilds the data from public sources. The portfolio version includes stage reports and model outputs in `outputs/` so the project results can be reviewed without committing large CSV files.
