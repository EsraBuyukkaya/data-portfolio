## How I Build Projects

Each project follows the same process:

1. Read a real job description or business problem.
2. Identify the skills and outcomes the employer is asking for.
3. Find or create appropriate public or synthetic data.
4. Build a working prototype with clear business logic.
5. Validate the output and explain limitations.
6. Document the project so a hiring manager can understand both the technical work and the business value.
